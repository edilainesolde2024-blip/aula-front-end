# 🧠 Jogo da Memória – Memória em Família

> Projeto desenvolvido como atividade prática da disciplina de **Frameworks Front-end**, utilizando **HTML, CSS e Vanilla JavaScript**.

---

## 📚 Sobre a Atividade

Este projeto foi desenvolvido a partir da **Atividade 01 da disciplina de Frameworks Front-end**, cujo objetivo é aplicar os conceitos introdutórios de desenvolvimento Front-end por meio da criação de uma aplicação utilizando:

* HTML;
* CSS;
* JavaScript (Vanilla JS);
* Git;
* GitHub;
* Vercel.

A proposta também busca proporcionar o primeiro contato prático com o desenvolvimento de aplicações Web, trabalhando conceitos fundamentais que serão utilizados posteriormente no estudo de frameworks como **React, Vue.js e Angular**.

## 💻 Sobre o Projeto

O projeto consiste em um **Jogo da Memória**, desenvolvido utilizando JavaScript puro.

A escolha do tema surgiu da ideia de transformar uma atividade acadêmica em uma experiência de **memória afetiva da família**.

Em vez de utilizar imagens genéricas, o jogo utiliza fotografias da família, fazendo com que cada partida represente uma oportunidade de relembrar pessoas, momentos e histórias especiais.

Dessa forma, o projeto une **aprendizado de programação e memória afetiva**, tornando a atividade acadêmica mais pessoal e significativa.

---

## ❤️ Memória Afetiva

A ideia do projeto vai além da criação de um jogo.

As fotografias utilizadas representam momentos e pessoas importantes da família. Dessa maneira, o desenvolvimento do jogo também se tornou uma forma de preservar essas lembranças através da tecnologia.

Cada carta do jogo representa uma fotografia e, ao encontrar os pares, o jogador revisita momentos especiais.

> **Programar também pode ser uma forma de preservar histórias e criar novas memórias. ❤️**

## 🎯 Objetivos do Projeto

### Objetivo geral

Desenvolver um jogo interativo utilizando tecnologias básicas de Front-end, aplicando os conhecimentos apresentados na disciplina.

### Objetivos específicos

* Desenvolver uma página Web utilizando HTML5;
* Criar uma interface visual utilizando CSS3;
* Utilizar JavaScript para implementar a lógica do jogo;
* Trabalhar com manipulação do DOM;
* Utilizar eventos de interação do usuário;
* Trabalhar com arrays e estruturas condicionais;
* Implementar a lógica de identificação dos pares;
* Utilizar Git para controle de versão;
* Hospedar o projeto no GitHub;
* Realizar o deploy da aplicação utilizando a Vercel.

---

## 🛠️ Tecnologias Utilizadas

### HTML5

Utilizado para estruturar os elementos da página e do jogo.

### CSS3

Utilizado para:

* Estilização da interface;
* Organização dos elementos;
* Layout do tabuleiro;
* Animações e efeitos visuais;
* Responsividade.

### JavaScript – Vanilla JS

O projeto utiliza **Vanilla JavaScript**, ou seja, JavaScript puro, sem a utilização de bibliotecas ou frameworks.

O uso do Vanilla JS nesta atividade é importante para compreender os fundamentos da linguagem antes da utilização de frameworks modernos.

Foram trabalhados conceitos como:

* Variáveis;
* Arrays;
* Funções;
* Estruturas condicionais;
* Eventos;
* Manipulação do DOM;
* Manipulação de classes CSS;
* Controle do estado das cartas;
* Comparação dos pares.

### Git

Utilizado para controle de versão do projeto.

### GitHub

Utilizado para armazenar e versionar o código-fonte do projeto.

### Vercel

Utilizada para realizar o **deploy** e disponibilizar o jogo na Web.

---

## 🎮 Funcionalidades

O jogo possui as seguintes funcionalidades:

* 🃏 Cartas com fotografias;
* 🔄 Sistema para virar as cartas;
