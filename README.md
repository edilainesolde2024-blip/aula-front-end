## Contexto da Aula

Esta aula inicial teve como foco a apresentação da disciplina, o plano de ensino e a contextualização do desenvolvimento front-end no mercado atual, destacando a importância dos frameworks para o desenvolvimento de aplicações modernas.

## 1. Contexto e Definição de Front-end

### Importância Estratégica
O uso de frameworks é um requisito estratégico para a competitividade das empresas, permitindo o desenvolvimento de interfaces mais rápidas, organizadas, reutilizáveis e de fácil manutenção.

### O que é Front-end?
Front-end é a camada da aplicação com a qual o **usuário interage diretamente**. É responsável por:

- Interface visual;
- Experiência do usuário (UX);
- Organização dos elementos da página;
- Comunicação com o processamento de dados (Back-end).

### Arquitetura de um Site

O desenvolvimento de uma aplicação envolve:

1. Definição do escopo;
2. Prototipação;
3. Design de UX/UI;
4. Validação das ideias por meio de testes e iterações.

---

## 2. Tecnologias e Ferramentas

### JavaScript (Vanilla JS)

- Linguagem de programação utilizada no desenvolvimento Front-end.
- O termo **Vanilla JS** refere-se ao JavaScript puro, sem bibliotecas ou frameworks.
- Serve como base para compreender qualquer framework moderno.

### Frameworks e Bibliotecas

Durante a disciplina serão estudadas tecnologias como:

- React
- Vue.js
- Angular

Os principais conceitos abordados incluem:

- Componentização;
- Reutilização de código;
- Gerenciamento de estado;
- Desenvolvimento de aplicações SPA (Single Page Applications).

### Versionamento e Deploy

As ferramentas utilizadas durante a disciplina serão:

- **Git** — Controle de versão;
- **GitHub** — Hospedagem de repositórios;
- **Vercel** — Publicação (Deploy) das aplicações.

A disciplina será desenvolvida por meio de:

- Aulas expositivas dialogadas;
- Discussões críticas;
- Estudos de caso da indústria;
- Desenvolvimento de projetos práticos.

O projeto deverá ser documentado como um **Mini TCC**, contendo:

- Planejamento;

---

## 4. Atividades Propostas

### Atividade 01

Desenvolver um projeto utilizando:

- HTML;
- CSS;
- JavaScript (Vanilla JS).

O projeto deverá:

- Estar versionado no GitHub;
- Ser publicado na plataforma Vercel.

### Atividade 02

Em grupos de **3 a 5 integrantes**, realizar:

- Criação de um repositório principal no GitHub;
- Escolha de um Framework Front-end;
- Elaboração de um relatório técnico sobre o framework escolhido.

---

## 5. Objetivos de Aprendizagem

Ao final da disciplina, o aluno deverá ser capaz de:

- Desenvolver interfaces modernas;
- Utilizar frameworks Front-end;
- Trabalhar com Git e GitHub;
- Publicar aplicações reais na web;
- Aplicar boas práticas de desenvolvimento de software.

---

## Resumo Geral

A disciplina tem como objetivo introduzir o aluno ao desenvolvimento Front-end moderno, utilizando JavaScript e frameworks amplamente adotados pelo mercado. Além do desenvolvimento técnico, também serão trabalhadas práticas de versionamento, publicação de aplicações e documentação de projetos, preparando o estudante para situações reais do ambiente profissional.
